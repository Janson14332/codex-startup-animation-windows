# 故障处理

| 现象 | 处理 |
| --- | --- |
| 找不到 Node.js / FFmpeg | 安装依赖并重新打开终端；确认 `node --version`、`ffmpeg -version`、`ffprobe -version` 可运行。需要时设置 `FFMPEG_BIN`、`FFPROBE_BIN`。 |
| 预览缺少素材 | 运行 `npm run setup` 或 `安装项目.cmd`；已有自定义配置却丢失文件时，重新选择素材。 |
| 更换素材后仍显示旧图 | 刷新或重新打开预览；完全退出 Codex 后从动画快捷方式启动。检查是否在当前环境的「图片设置」保存了覆盖图。 |
| 尚未找到 Codex 主窗口 | 从托盘完全退出官方应用，确认无旧版本后台实例，再启动；官方更新后若持续失败，需适配窗口。 |
| 快捷方式失效 | 保持整个项目目录完整；移动后重新运行 `安装项目.cmd`。 |
| 轮廓过少 | 选择边缘更清晰的素材。纯色画面无法生成有效线稿。 |
| 需要查看启动错误 | 桌面正式入口隐藏运行，失败时弹窗并写入 `.build/last-launch.log`；运行 `扩展启动Codex.cmd` 可在命令行窗口中看到完整过程。 |
| 双击桌面入口没有任何反应 | 先确认 Codex 是否已在运行；仍无反应时运行 `扩展启动Codex.cmd` 查看输出，或重新运行 `安装项目.cmd` 重建快捷方式。 |

点击跳过或按 Esc 可结束动画。按 Ctrl+Alt+B 打开当前环境的壁纸设置；0% 隐藏壁纸，或选择「关闭美化，恢复 Codex 外观」。完全退出应用后从官方图标启动，可关闭本次调试端口。

浏览器预览与真实应用的 IndexedDB 独立。项目更换素材入口更新磁盘文件；当前环境的图片设置只影响当前环境。
